# Combiner — mash up any two games

**Free, browser-based game mashups that run on phones and PCs.** Drop the hero of one game into the world of another and play it instantly, invite friends with a link, or describe any combo ("Minecraft × Skyrim") and let AI build a playable version.

- 🆓 **Free**: no account, no download, no server bills. Hosts free on GitHub Pages; AI creation works with free chatbots or free API tiers.
- 📱 **Mobile first**: on-screen joystick + buttons on phones, keyboard/gamepad on PC, installable as an app (PWA) and playable offline.
- 🎮 **64 instant mashups**: 8 built-in games × 8 built-in games, every pair playable.
- ✨ **AI creator**: generate, refine and fix games by chatting; share them as links.
- 👥 **Multiplayer links**: peer-to-peer rooms with an invite link or QR code.

## How it compares to melty.gg

[Melty](https://melty.gg) (YC F26) is a **Windows launcher**: it installs AI-written mods that fuse two **PC games you already own** (e.g. "SkyCraft": play Skyrim as a Minecraft player), restores the original files afterwards, lets friends join through invite links, and lets creators publish mashups made with coding agents.

Modding real commercial PC games can't work on a phone, so Combiner keeps the same idea and loop but moves it to the web:

|                  | Melty                                  | Combiner                                                         |
| ---------------- | -------------------------------------- | ---------------------------------------------------------------- |
| Platform         | Windows app                            | Any browser: iPhone, Android, PC, Mac, Chromebook                |
| What a mashup is | A mod for two games you own            | A self-contained browser game                                    |
| Cost             | Free app, needs the games              | Free, nothing to buy                                             |
| Instant mashups  | Catalogue of published mods            | 64 built-in mashups generated by the engine                      |
| Make your own    | Paste instructions into a coding agent | AI studio: free copy-paste mode, free API tiers, or your own key |
| Multiplayer      | Invite link / public lobby             | Invite link + QR code, peer-to-peer                              |
| Sharing          | Publish to the store                   | Link that contains the whole game, or download the `.html`       |

## Using it

1. **Play** — open the home page, pick _"Play as the hero from"_ and _"In the world of"_, press **Play now**. Example: _Blockrim_ is the Blockcraft miner (mine/build) in Dragon Realm (ruins, word walls, a dragon).
2. **Play with friends** — in any game tap 👥, send the link or show the QR code. Built-in mashups become a race (see each other as ghosts, live progress bars, "restart race for everyone"). AI games get a messaging API.
3. **Create with AI** — name two games and an optional twist. Then:
   - **Copy & paste mode (default, free, no key):** Combiner copies a ready prompt → paste into ChatGPT / Gemini / Claude / DeepSeek / Copilot → paste the answer back.
   - **OpenRouter free models:** free key, model `openrouter/free`.
   - **Google Gemini:** free-tier key from AI Studio, model `gemini-flash-latest`.
   - **Anthropic Claude:** your own key; Claude Opus 5.5 by default (Sonnet 5.5 / Haiku 5.5 selectable).
   - **Any OpenAI-compatible API:** Groq, Together, LM Studio, Ollama…

   The game previews immediately and is saved to **My games**. Refine it ("add a boss"), undo, fix crashes with one tap (runtime errors are captured), share as a link or download the file.

## How it works

```
src/
  engine/      Canvas game engine for the built-in mashups
    heroes.ts    8 heroes: movement style + abilities (jump, mine, place, sword, shout, flap, fireball, shoot, warp, ball, power…)
    worlds.ts    8 worlds: seeded level generator, enemies, goal, theme
    enemies.ts   enemy / projectile / ball behaviours
    game.ts      game loop, combat, pickups, camera, multiplayer snapshot
    art.ts       procedural pixel-art sprites and tiles (no image assets)
  player/      runs games: engine runner, touch pad, keyboard/gamepad, WebAudio sfx,
               sandbox for AI games + the injected Combiner SDK
  ai/          prompt, streaming providers, response parser
  net/room.ts  PeerJS rooms (host relays, guests receive the game itself)
  data/        IndexedDB library, settings, share-link encoding, mashup names
  views/       home, mashup page, player, AI studio, library, settings
```

**Mashup engine.** Each base game contributes a _hero_ (how you move and what your buttons do) and a _world_ (level, enemies, objective). Any hero can be dropped into any world: movement adapts to the world's camera (side view has gravity, top-down doesn't), so a snake slithers through a platformer, a spaceship thrusts through a ghost maze, and a miner digs through Brick Breaker. Levels are seeded, which keeps multiplayer races identical on every device, and fixed-screen worlds reshape themselves to portrait or landscape screens.

**AI games run in a locked sandbox.** Generated HTML runs in an `<iframe sandbox="allow-scripts">` without `allow-same-origin`, so it gets an opaque origin and cannot read your library, settings or API keys. Combiner injects a small SDK first that:

- turns the on-screen joystick and A/B/C buttons into real `keydown`/`keyup` events (arrows, Space, X, C), so any keyboard game is playable on a phone;
- reports runtime errors back to the app (for "Fix with AI");
- bridges multiplayer messages;
- shims `localStorage` and resumes WebAudio on the first tap.

**Multiplayer.** WebRTC data channels through [PeerJS](https://peerjs.com). The free public PeerJS server only introduces players; game data flows device-to-device. The host sends the game to each guest on join, so invite links stay short and work for AI games that only exist on the host's device.

**Share links** put the whole game, deflate-compressed, in the URL fragment (`#/s/…`). Fragments are never sent to any server.

### Writing games for Combiner (humans or AI)

```html
<meta name="combiner-controls" content="a:Jump b:Attack c:Build" />
<!-- or content="touch" for tap/drag games: the on-screen pad is hidden -->
<script>
  addEventListener('keydown', (e) => {
    /* arrows/WASD move, Space = A, X = B, C = C */
  });
  const { x, y } = window.Combiner?.input ?? { x: 0, y: 0 }; // analog joystick
  Combiner.net.onMessage((data, fromId) => {}); // multiplayer
  Combiner.net.send({ x: 10, y: 20 });
  Combiner.net.onPlayers((players) => {}); // [{ id, name, color }]
  Combiner.setScore(42);
  Combiner.gameOver(true, 42);
</script>
```

## Develop

Requires Node 22.12+.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # engine simulations for all 64 mashups, AI parsing, share links, SDK injection
npm run lint       # prettier + TypeScript
npm run build      # static site in dist/
```

## Deploy for free

- **GitHub Pages:** push to `main`, then in the repo's _Settings → Pages_ set _Source_ to **GitHub Actions**. `.github/workflows/deploy.yml` tests, builds and publishes.
- **Anywhere static:** upload `dist/` to Netlify, Cloudflare Pages, Vercel or any web server. All paths are relative, so sub-folders work.

Optional, for multiplayer on strict networks: add a TURN server in _Settings → Multiplayer network_, or self-host a [PeerJS server](https://github.com/peers/peerjs-server) and enter its URL there (everyone in a room must use the same server).

App icons are rendered from `public/icons/icon.svg` by `scripts/make-icons.mjs` (needs `playwright-core` and Chromium).

## Limitations

- It does not mod real commercial games. That needs a desktop and the game files; phones can't do it. Mashups here are original browser games inspired by famous ones.
- AI game quality depends on the model. Free models and free tiers are rate-limited and less reliable than paid models. Copy & paste mode works with whatever chatbot you have.
- Peer-to-peer connections can fail on some mobile/corporate networks without a TURN relay.

The built-in games are original homages. Minecraft, Skyrim, Flappy Bird, Super Mario Bros., Snake, Asteroids, Breakout, Pac-Man and other names belong to their owners and are not affiliated with this project.
